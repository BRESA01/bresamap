## Что внутри

- **38 стран** с отдельной страницей на каждую: визовый режим, налоги, стоимость жизни, язык, валюта.
- **Блюда, традиции, факты и история** каждой страны: коротко и так, чтобы хотелось листать дальше.
- **Подбор страны**: отвечаешь на несколько вопросов, сайт показывает подходящие варианты.
- **Сравнение стран** рядом друг с другом.
- **Викторина** по флагам, столицам и блюдам с картинкой результата, которой можно поделиться.
- **Страна дня**, случайная страна, избранное и умный поиск по названиям и алиасам.
- **Звуки интерфейса** (синтезируются в браузере, отдельных файлов нет) и выключатель.
- Быстрая загрузка: никаких фреймворков, всё на чистом HTML, CSS и JavaScript.

## Как устроен сайт

| | |
|---|---|
| **Тип** | Статический сайт, сервер не нужен |
| **Страницы** | Главная плюс по странице на каждую страну в `/pereezd/<страна>/` |
| **Дизайн** | Стикерный стиль: тёмный фон, бумажные карточки, обводка и жёсткие тени |
| **Шрифты** | Luckiest Guy, Unbounded, Nunito |
| **Флаги и еда** | Рендерятся в WebP, не зависят от шрифтов эмодзи на Windows |
| **Звуки** | Web Audio API |
| **SEO** | Отдельные title и description, canonical, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt` |
| **Хостинг** | Vercel, домен `bresamap.ru` |

## Структура

```
index.html            главная
404.html              страница ошибки
pereezd/<страна>/     страницы стран
css/                  стили
js/                   логика: ядро, главная, страна, инструменты, аналитика
img/                  флаги, иконки блюд, логотипы
sitemap.xml           карта сайта
robots.txt
```

## Запустить у себя

Сайт статический, достаточно любого локального сервера:

```bash
git clone https://github.com/BRESA01/bresamap-site.git
cd bresamap-site
python -m http.server 8000
```

После этого открой http://localhost:8000.

## Важно

Данные по странам собраны в справочных целях и могут устареть: правила въезда, налоги и цены меняются. Перед переездом проверяй информацию на официальных сайтах консульств и миграционных служб.
